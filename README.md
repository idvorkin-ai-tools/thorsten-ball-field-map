# Thorsten Ball, mapped

A field map of Thorsten Ball ([mrnugget](https://github.com/mrnugget)): the Register Spill newsletter and its Joy & Curiosity issues, the Raising an Agent podcast, How to Build an Agent and his other agentic-coding writing, the Monkey books (Writing An Interpreter In Go, Writing A Compiler In Go), and how he works.

Live: https://idvorkin-ai-tools.github.io/thorsten-ball-field-map/

Static HTML, no build. `index.html` is the spine; `pages/pNN.html` are the units; `paper.css` is shared with the other field maps. Summaries are original; quotes link to Thorsten's public writing and episodes.
